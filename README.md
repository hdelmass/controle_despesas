# Controle de Despesas

## Descrição do Projeto  
Controle simples de despesas pessoais via terminal, desenvolvido em Python.

## Estrutura do Projeto  
- `main.py` – menu e interface com o usuário  
- `despesas_controller.py` – funções de adicionar, listar e calcular despesas  
- `database.json` – arquivo de armazenamento das despesas  
- `README.md` – documentação e orientações

## Funcionalidades  
- Adicionar despesas  
- Listar despesas registradas  
- Calcular total das despesas

## Workflow com Git  
- Inicialização local do repositório e push para GitHub  
- Criação e merge de branch (`adicionar_despesas`) como parte do versionamento

## Como Executar  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/hdelmass/controle_despesas.git
   cd controle_despesas
2. Execute o programa:

python main.py


Utilize o menu interativo para experimentar as funcionalidades.
